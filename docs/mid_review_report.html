1. Executive Summary for Project Manager

PolyglotMesh is an enterprise multi-language execution platform built with Spring Boot 3.3.5 and the Oracle GraalVM Truffle Polyglot Engine 24.1.1. It enables client applications to safely evaluate untrusted guest scripts (JavaScript ECMAScript 2023 and Python 3.11+ via GraalPy) in-process within a shared Java Virtual Machine while enforcing absolute hardware-level and statement-level sandboxing.

During Weeks 1 and 2, all 6 mandatory internship deliverables were completed, verified, and committed across 12 distinct calendar days. The platform includes an interactive single-page developer console, a resilient PostgreSQL/JPA audit trail, and automated watchdog timeout protection.

2. 4-Layer Defensive Security Architecture

Security Layer Truffle API Implementation Attacks Mitigated
Layer 1: Host Lockdown HostAccess.EXPLICIT + class lookup filter returning false Prevents reflection escapes, access to java.lang.System, Runtime.exec(), and classloaders.
Layer 2: I/O Virtualization IOAccess.NONE + EnvironmentAccess.NONE Blocks host filesystem reads/writes, network sockets, port binding, and OS environment variable snooping.
Layer 3: AST Statement Limits ResourceLimits.statementLimit(maxStatements) Intercepts algorithmic complexity attacks and while(true) infinite loops within milliseconds.
Layer 4: Daemon Watchdogs Future.get(timeoutMs, TimeUnit.MILLISECONDS) + Context close Thread-level watchdog timer that terminates long-running script executions and releases worker threads.
