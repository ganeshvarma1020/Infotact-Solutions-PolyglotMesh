Problem Statement

The Danger of Untrusted Script Execution

  • Remote Code Execution (RCE): Guest scripts attempting host reflection (`java.lang.System.exit()`, `Runtime.getRuntime().exec()`).
  • Denial of Service (DoS): Unbounded while(true) loops that peg host CPU cores at 100%.
  • Memory Exhaustion (OOM): Memory leak attacks that bring down production microservices.
  • SecurityManager Deprecation: Historical Java SecurityManager is deprecated and removed in modern JDKs.
  • Container Overhead: Docker-per-execution approaches impose 300–800 ms cold start latencies and 64+ MB memory overhead per request.

Security Boundaries

4-Layered Defense-in-Depth Model

  • 1. Zero Class Reflection: `HostAccess.EXPLICIT` + `allowHostClassLookup(c -> false)` stops all host class reflection.
  • 2. Statement Counter Quota: Truffle `ResourceLimits.statementLimit()` deterministically kills runaway loops before host CPU saturation.
  • 3. Hard Wall-Clock Watchdog: Bounded thread `Future.get()` triggers `context.close(true)` asynchronously on timeout expiry.
  • 4. Complete I/O Quarantine: `IOAccess.NONE` disables all file system, network sockets, sub-processes, and thread creation.

OOP Domain Model

Clean Object-Oriented Architecture

  • Domain Entities & Records: `SupportedLanguage` enum, `ExecutionRequest` & `ExecutionResponse` records with Jakarta Bean Validation.
  • Core Service: `SandboxExecutionService` handles thread submission, watchdog timeouts, and stream capture.
  • Configuration: `PolyglotConfig` creates singleton shared `Engine` and `HostAccess` beans.
  • REST API: `SandboxController` provides `/execute`, `/history`, and `/languages` endpoints.
  • Global Exception Handling: `GlobalExceptionHandler` standardizes HTTP 400 and 422 error payloads.

Persistence Layer

PostgreSQL Audit Logging

  • Entity: `ExecutionAuditLog` mapped to `execution_audit_logs` table in PostgreSQL.
  • Captured Telemetry: ID, language, sourceCode, status, returnValue, stdout, stderr, errorMessage, durationMs, maxStatements, executedAt.
  • Repository: `ExecutionAuditRepository` provides fast indexed lookup: `findTop25ByOrderByExecutedAtDesc()`.
  • Dual Persistence Modes: Production PostgreSQL 16 container, with seamless local H2 fallback support.
